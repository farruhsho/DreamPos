# DreamPOS — статус проекта

_Обновлено: 2026-11-24_

**Продукт:** DreamPOS — offline‑first POS/ERP для розничных магазинов (Центральная Азия).
**Стек:** Flutter 3.38 · Riverpod 3 · go_router · drift (SQLite). См. `DECISIONS.md`, `docs/ARCHITECTURE.md`.
**Репозиторий:** https://github.com/farruhsho/DreamPos (ветка `main`).

## Как продолжить работу (новый сеанс)
1. Прочитать этот файл, `DECISIONS.md`, `docs/ARCHITECTURE.md`, `QUALITY_CHECKLIST.md`.
2. `flutter pub get` → `flutter analyze` → `flutter test`.
3. Схема БД изменилась? `dart run build_runner build -d --force-jit` (AOT‑режим build_runner падает из‑за build hooks sqlite3).
4. Взять верхнюю задачу из «Дорожной карты».

## Дорожная карта (следующие этапы)
1. Интеграция модулей + сквозной UX‑аудит в запущенном приложении.
2. Синхронизация нескольких касс (Supabase, D-003), коды касс в номерах чеков.
3. Локализация uz / tj / en (D-012).
4. Фискализация и эквайринг — после решения владельца (D-014).
5. Печать на ESC/POS напрямую (без диалога), денежный ящик.
6. Лицензирование/подписки (серверная часть).
